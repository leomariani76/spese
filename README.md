# Le mie spese

Web app per iPhone che tiene traccia delle spese mese per mese, importa i pagamenti Nexi tramite i Comandi Rapidi e permette di inserire a mano le spese in contanti. I dati restano solo sul telefono: questo repository contiene solo il codice.

App: https://leomariani76.github.io/spese/

Installazione e configurazione dei Comandi Rapidi: [LEGGIMI.md](LEGGIMI.md)
